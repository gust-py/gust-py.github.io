publicar no github pages gratuitamente

o github pages permite hospedar este site estático em minutos sem custos:

  1. copie o código deste arquivo e salve como index.html.
  2. crie um repositório público no seu github.
  3. faça o upload do arquivo index.html na raiz do repositório.
  4. vá em settings > pages.
  5. em branch, escolha main e clique em save.
  6. o simulador estará online no link fornecido pelo github!
